# Security

Report vulnerabilities privately: **Security > Report a vulnerability** on this repository. Please don't open a public issue.

asc-payout keeps your API keys and settings in its configuration folder and downloaded reports in its cache folder (`asc-payout status` shows both). It connects to App Store Connect with your key and to public exchange-rate services with currency codes and dates only. There is no telemetry.

Never paste a `.p8` key, Issuer ID or report into an issue.
